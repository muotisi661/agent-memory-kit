# 记忆系统重构：从云端记忆服务迁到本地四层

## 背景

云端记忆服务返回 402（额度耗尽）。当月第三次，说明这个依赖不可持续。
同时内置 memory 已经到 91%，每天都要清理。

## 决策

放弃云端记忆服务，改为本地四层结构：

- L0 内核（≤2200 字符，自动注入）
- L1 Markdown 知识库（按用途分目录）
- L2 qmd 语义索引
- L3 会话归档

## 为什么不用数据库

试过 SQLite + 向量扩展。问题是：

1. 记忆的主要消费者是语言模型和人，两者最擅长读 Markdown
2. 坏了不好修 —— 文本文件能用记事本救回来，数据库不能
3. 不能用 git diff 看"记忆是怎么变的"，而这是最有价值的部分

## 迁移结果

- 内置 memory 占用：91% → 34%
- L1 文件数：0 → 27
- 检索命中率：先从 0（云端挂了）到 ~80%（抽 10 次查询手测）
