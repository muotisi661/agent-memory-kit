# LanceDB 嵌入踩坑

## 症状

索引显示构建成功，语义搜索返回的结果完全随机。没有任何报错。

## 原因

嵌入模型的输出维度与建表时声明的不一致：

- 建表用了 `dim=1536`（照着云端模型的文档抄的）
- 实际本地模型 `bge-small-zh` 输出 512 维

写入时不报错，但向量被截断/补零，相似度计算全是噪声。

## 解法

1. 建表前先确认模型真实输出维度：
   ```python
   len(embed("测试"))   # 不要信文档，跑一次
   ```
2. 表结构里的 `dim` 必须与之一致
3. 建完立刻抽查一条记录：
   ```python
   tbl.search([0.0]*DIM).limit(1).to_list()   # 能返回说明结构可用
   ```

## 通用教训

**"索引成功"不等于"索引可用"。** 任何向量索引建完都要拿真实数据抽查一次，
验证维度、验证非空、验证检索结果和查询语义相关。
