# 部署静态站

纯静态站点（Vite/Next export）推到 GitHub Pages 或 Cloudflare Pages 的固定流程。

## 前置检查

```bash
node -v          # 需要 >= 18
ls package.json  # 确认 build 脚本存在
```

## 步骤

1. **本地构建并验证**
   ```bash
   npm ci
   npm run build
   npx serve dist    # 或 out/
   ```
   打开浏览器确认首页、路由跳转、图片都正常。

2. **检查相对路径**
   - 部署到子路径（`/repo-name/`）时，base 必须配成 `/repo-name/`
   - 忘了这一步 → 部署后白屏，控制台报 404

3. **推送到 gh-pages**
   ```bash
   git subtree push --prefix dist origin gh-pages
   ```
   或用一个专门的 deploy 分支 + GitHub Actions。

4. **等 1-2 分钟**，再打开线上地址确认。GitHub Pages 有缓存，强刷。

## 常见故障

| 现象 | 原因 |
|---|---|
| 白屏 + 大量 404 | base 路径没配 |
| 图片裂开 | 用了绝对路径 `/img/x.png`，改成相对路径 |
| 样式丢失 | CSS 被 tree-shake 掉了，检查构建产物里有 .css 文件 |
