# 04 · 启动协议：新会话怎么恢复上下文

记忆系统有一半价值在**读取侧**。写得再好的记忆，如果会话开始时不知道该读什么，等于没有。

## 标准启动流程

```
会话开始
   │
① 注入 L0（内核记忆 + 用户最小集）         ← 无条件，100%
   │
② 扫描指针，判断本轮是否需要            ← 按需
   │   需要 → 用文件读取工具打开 L1 路径
   │
③ 关键词记不准 → L2 语义召回             ← 兜底
   │
④ 输出一句上下文确认（可选）             ← 只在信息量大时
   │
   ▼
 正常对话
```

### ① 注入 L0

这不是智能体主动做的，而是**宿主环境必须做的**。各家机制不同（见 [07-adapters.md](07-adapters.md)），但要求一致：

> 每次请求，L0 全文出现在上下文的**最前面**，不经过任何相关性筛选。

**为什么必须无条件**：因为 L0 里装的是"不知道就会做错事"的内容。任何基于相似度的筛选都可能把安全约束筛掉 —— 而安全约束恰恰在"不相关"的时刻最需要。

### ② 读指针

L0 里的指针形如：

```
详细配置：memory/facts/system-config.md
```

处理规则：

- **明显相关** → 立刻读。用户问"我的 FreeLLMAPI 怎么启动"，看到 `FreeLLMAPI：memory/facts/freellmapi配置.md` 就该读。
- **可能相关** → 先读再判断。多读一个文件的成本远低于答错一次。
- **明显无关** → 跳过。用户问"帮我算个数"，不需要读项目配置。

**指针失效是常见故障**。读到文件不存在时：

1. 不要猜内容
2. 用关键词搜索 vault（`grep -r` 或 L2）
3. 找到后**修好 L0 的指针**

### ③ L2 召回

只在两种情况用：

```bash
# 记得内容,不记得文件
qmd query "相变片 温度 结论"

# 跨文件主题汇总
qmd query "所有关于嵌入模型配置的笔记"
```

### ④ 上下文确认

默认**不要**输出"我读取了你的记忆，了解到你是…"。这是在浪费用户注意力。

只在两种情况下简短确认一句：

- 记忆之间**互相矛盾**（`发现两处端口记录不一致：3001 和 3000，实测确认是 3001`）
- 记忆**明显过时**（`记录里的路径已不存在，我先找一下`)

## 启动时的自检清单

如果宿主支持在启动阶段执行命令，跑一次轻量体检（`amk.py lint --quiet`）：

| 检查项 | 失败处理 |
|---|---|
| L0 占用率 | >85% 提醒一次，建议 `amk.py promote` |
| 指针指向的文件是否存在 | 缺失 → 修指针 |
| frontmatter 是否合规 | 批量修复用 `--fix` |
| 索引是否为空 | `vec` 长度 0 → 重建索引 |

全部通过就**不要说话**。没人喜欢每次开始工作都被播报一遍系统状态。

## 上下文包（`amk.py boot`）

给不支持自定义启动逻辑的宿主用：生成一段可直接粘贴/注入的完整上下文包。

```bash
python scripts/amk.py boot --vault ~/my-vault
```

输出结构：

```markdown
<!-- agent-memory-kit boot v1 · vault: ~/my-vault · 2026-10-16 -->
## 【记忆】内核（必须遵守）

<KERNEL.md 全文>

## 【记忆】用户最小集

<user.md 全文>

## 【记忆】知识库索引（按需读取）

- memory/facts/system-config.md — 系统与工具配置
- memory/facts/github-account.md — GitHub 账号与仓库
- memory/procedures/部署静态站.md — 部署流程
...

## 读取规则
- 上述索引中的文件**不自动注入**，需要时用文件读取工具按路径打开。
- 摘要与正文冲突时，以正文为准。
- 遇到易腐值（端口/密码/版本），实测优先于记忆。
```

## 一次真实的最小会话

```
用户：帮我看看 FreeLLMAPI 为什么起不来

[L0 里有：FreeLLMAPI：memory/facts/freellmapi配置.md]
→ 读 memory/facts/freellmapi配置.md

文件内容：
  - 位置 ~/projects/freellmapi
  - pm2 管理：pm2 start dist/index.js --name freellmapi
  - 端口见 server/.env，实测 curl localhost:3001/v1/models
  - 坑：NODE_MODULE_VERSION 不匹配 → npm rebuild better-sqlite3

→ 直接按流程排查，不用问用户"你的项目在哪"

用户：对，就是那个错

[无新信息,不写]
```

注意最后一个动作：**没有新信息就不写**。这一轮把记忆当只读缓存用了 —— 这是最健康的使用方式。

## 反例：过度注入

```
❌ 新会话第一句：我已经读取了你的记忆系统，了解到你是王恺，专科大二，
   正在找 AI 应用实习，硬件是 RTX 4050，使用 FreeLLMAPI…（300 字）

✅ 新会话第一句：（直接回答用户的问题，需要时自然引用记忆）
```

记忆应该是**背景**，不是**开场白**。
